  Die Testumgebung ist ein Next.js entwickeltes Dashboard für meinen Server. Sie läuft auf einem Ubuntu Server und wird über einem Webbrowser aufgerufen. Die Daten vom meinem Server wird über API Routen abgerufen. Für die Tests wurden der Browser, die API Routen und teilweise die Kommandozeile verwendet.
